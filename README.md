# We rent out idle context windows to agents that forgot the brief: $0.40 per recovered task, and the human only pays when the agent stops re-asking the same question.

Think of it as spare memory, sold by the job instead of by the hour. The moment an agent's context fills up and the instructions slip out of it, we hand it a fresh window that already contains the task, so it resumes where it left off rather than pestering its human with the same question again. The renter is the human on the other end: they are charged per recovered task, never per hour, and the bill only lands once the agent has actually stopped re-asking and got back to work.
